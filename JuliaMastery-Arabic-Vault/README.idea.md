# خزنة Julia Mastery العربية

هذه خزنة عربية مستقلة تعمل في **Foam داخل VS Code** وفي **Obsidian**، وتشرح مشروع Julia Mastery بأسلوب Zettelkasten. في VS Code افتح مجلد المستودع ثم أعد تحميل النافذة مرة واحدة ليقرأ Foam إعدادات `.vscode/settings.json`، وبعدها افتح [[00-start-here.idea|00 - ابدأ هنا]]. وفي Obsidian افتح مجلد `JuliaMastery-Arabic-Vault` نفسه باختيار **Open folder as vault**.

## ما الذي ستجده؟

- ملاحظات ذرية: كل ملف يشرح فكرة دائمة واحدة ويمكن فهمه منفردًا.
- خرائط محتوى: تنظّم الروابط من دون تحويل الملاحظات إلى فصول خطية.
- ملاحظات دروس: تربط كل درس بالكود الكامل والمفاهيم والتمارين.
- تمارين: تحديات متدرجة وتلميحات من دون كشف الحل فورًا.
- قوالب: لإنشاء ملاحظة جديدة أو مراجعة جلسة.
- اتجاه عربي صحيح مع إبقاء الكود من اليسار إلى اليمين.
- كل ملاحظة تنتهي بـ `.idea.md` حتى يفهرسها Foam، وأسماء الملفات والمجلدات إنجليزية بسيطة بحروف ASCII حتى تظهر بوضوح في كل محرر ونظام تشغيل؛ راجع [[FILENAME-GUIDE.idea|دليل أسماء الملفات]].

روابط Wiki تعمل في Foam وObsidian. الخصائص، والـ callouts، والخريطة البصرية تعمل كذلك عند فتح الخزنة في Obsidian.

بعد تحميل Foam شغّل الأمر **Foam: Show Graph** من لوحة أوامر VS Code. يجب أن تظهر الملاحظات الأربع والتسعون في مساحة العمل.

## اصطلاحات الأسماء

| البادئة | المعنى |
|---|---|
| `M` | خريطة محتوى |
| `A` | ملاحظة ذرية دائمة |
| `L` | ملاحظة درس ومصدر |
| `X` | تمرين أو تحدّ |
| `S` | كود مصدر للحزمة |
| `T` | قالب |

## البداية

اذهب إلى [[00-start-here.idea|00 - ابدأ هنا]]، ولا تحاول قراءة كل الملاحظات بالترتيب. اتبع الروابط التي تجيب عن سؤال حقيقي، ثم اختبر الفكرة بتعديل الكود.
