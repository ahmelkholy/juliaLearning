# دليل أسماء الملفات

أصبحت جميع أسماء الملفات والمجلدات بحروف إنجليزية بسيطة من نوع **ASCII**، وتنتهي كل ملاحظة بـ `.idea.md` حتى يتعرّف إليها Foam داخل VS Code. هذا يمنع ظهور الحروف العربية منفصلة أو على هيئة رموز غير مفهومة في بعض المحررات وأنظمة التشغيل. بقيت عناوين الملاحظات، والشرح، والأسئلة، والروابط الظاهرة بالعربية، وبقي كود Julia كما هو.

النهاية الحقيقية ما زالت `.md`، ولذلك تظل الملفات Markdown عادية ويمكن فتحها أيضًا في Obsidian وأي محرر نصوص.

يضبط ملف `.vscode/settings.json` Foam ليفهرس النمط `JuliaMastery-Arabic-Vault/**/*.idea.md`، ويعرض العنوان العربي في اقتراحات الروابط، ويحدّث روابط Wiki عند نقل الملاحظات.

## كيف تقرأ اسم الملاحظة؟

يتكوّن الاسم من ثلاثة أجزاء:

```text
A17-type-stability-enables-inference.idea.md
│   │                                  └── صيغة Markdown التي يفهرسها Foam
│   └───────────────────────────────────── وصف إنجليزي قصير للفكرة
└───────────────────────────────────────── رقم ثابت يعرّف الملاحظة
```

الجزء الأهم هو المعرّف في البداية، مثل `A17`. يمكنك البحث بهذا المعرّف داخل Foam أو Obsidian للوصول إلى الملاحظة بسرعة، ثم قراءة عنوانها العربي داخل الملف.

## معنى المجلدات

| المجلد | محتواه |
|---|---|
| `notes` | الملاحظات الذرية التي تشرح فكرة واحدة |
| `maps` | خرائط المحتوى التي تربط الأفكار |
| `lessons` | الدروس التطبيقية الكاملة |
| `exercises` | التمارين والتحديات |
| `sources` | نسخ مشروحة من كود المستودع |
| `templates` | قوالب تدوين ومراجعة التعلم |
| `attachments` | المرفقات التي ستضيفها لاحقًا |

## معنى بادئة المعرّف

| البادئة | المعنى | مثال |
|---|---|---|
| `A` | ملاحظة ذرية | `A01-methods-belong-to-functions.idea.md` |
| `M` | خريطة محتوى | `M03-performance-and-compiler.idea.md` |
| `L` | درس | `L06-concurrency.idea.md` |
| `X` | تمرين | `X04-matrix-free-operator-and-cg.idea.md` |
| `S` | كود مصدر مشروح | `S02-ode-solver-source.idea.md` |
| `T` | قالب | `T01-new-atomic-note.idea.md` |

## من أين أبدأ؟

1. افتح [[00-start-here.idea|صفحة البداية]].
2. انتقل إلى [[maps/M00-julia-mastery-map.idea|خريطة إتقان Julia]].
3. افتح [[lessons/L01-dispatch-and-types.idea|الدرس الأول]].
4. استخدم [[julia-mastery-map.canvas|الخريطة البصرية]] إذا كنت تفضّل رؤية العلاقات.

> [!tip] إذا بقيت الأسماء القديمة ظاهرة
> أعد تحميل نافذة VS Code لتحديث فهرس Foam. وإذا كنت تستخدم Obsidian، فأغلق الخزنة ثم افتح مجلد `JuliaMastery-Arabic-Vault` مرة أخرى.

## قاعدة إنشاء ملف جديد

استخدم حروف `a-z` والأرقام والشرطة `-` فقط في اسم الملف، وأنهِ كل اسم جديد بـ `.idea.md`. ضع العنوان العربي الكامل داخل الملاحظة. ابدأ من [[templates/T01-new-atomic-note.idea|قالب الملاحظة الذرية]] حتى تحافظ على البنية نفسها.
